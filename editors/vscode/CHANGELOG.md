# Change Log

All notable changes to the "sanemark" extension will be documented in this file.

## [0.1.0] - 2026-09-04

- Initial release of the Sanemark VS Code extension.
- Added language server client integration over stdio.
- Automatic binary acquisition from GitHub Releases with fallback to system `$PATH` and `sanemark.serverPath`.
- Commands for reference link conversion, moving references to bottom, copying inlined markdown, and journal daily notes.
- Complete settings schema for formatting, diagnostics, path completions, snippets, and journal configuration.
